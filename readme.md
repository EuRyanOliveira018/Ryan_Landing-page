🚀 Como executar

1. Clone o repositório

git clone URL_DO_REPOSITORIO

2. Entre na pasta

cd nome-do-projeto

3. Abra no VS Code

Abra a pasta do projeto no Visual Studio Code.

4. Execute com Live Server

Instale a extensão Live Server no VS Code.

Depois:

Botão direito em index.html → Open with Live Server

O portfólio será aberto automaticamente no navegador.

📧 Configuração do EmailJS

Para utilizar o formulário de contato, é necessário configurar uma conta
no EmailJS.

No script.js, configure sua Public Key, Service ID e
Template ID:

emailjs.init({
    publicKey: "SUA_PUBLIC_KEY"
});

await emailjs.sendForm(
    "SEU_SERVICE_ID",
    "SEU_TEMPLATE_ID",
    formulario
);

⚠️ Segurança

Não coloque Secret Keys ou outras credenciais privadas no código
público do GitHub.

A Public Key do EmailJS é própria para uso no lado do cliente, mas
informações secretas nunca devem ser expostas.

🤖 Configuração do reCAPTCHA

O formulário utiliza uma Site Key do Google reCAPTCHA.

No index.html:

<div class="g-recaptcha" data-sitekey="SUA_SITE_KEY"></div>

E o script do Google:

<script src="https://www.google.com/recaptcha/api.js" async defer></script>

A Secret Key do reCAPTCHA não deve ser publicada no GitHub.
